## 比特一瞥 BitGlance 1.2.2

Windows 桌面 BTC / ETH / SOL USDT 永续价格小工具，支持迷你悬浮窗和 K 线。

### 功能

- 三种 USDT 永续合约最新成交价，Bitget 公开行情，无需登录。
- 迷你窗背景与数字不透明度分离，可隐藏单位与涨跌幅；双击展开、拖动移动。
- 24H / 7D 折线与 1m / 5m / 15m / 1h K 线，成交量、缩放、平移与悬停详情。
- 明暗主题、托盘与独立窗口位置记忆。

### 本版整理

补齐 GitHub 文档、来源声明、自动构建和发布包校验。功能沿用 1.2.1 的鼠标交互修复版本。

### 使用

下载 `BitGlance-v1.2.2-Windows.zip`，解压后运行 `BitGlance.exe`。需要 Windows 10 / 11 和 .NET Framework 4.8。ZIP 包含对应源码、构建脚本与许可证；`.sha256` 文件用于校验下载。

0% 背景保留 Alpha=1/255（约 0.39%）的点击层，避免数字空隙穿透鼠标。行情定时轮询，未收盘 K 线会变化。
